# Hatirjheel Interactive Scene Simulation using OpenGL

## Overview

This project is an interactive 2D simulation of **Hatirjheel, Dhaka**, developed using **C++ and OpenGL (GLUT)**. The simulation recreates the scenic environment of Hatirjheel with animated vehicles, boats, birds, weather effects, and multiple time-of-day modes.

The project was developed as part of a Computer Graphics coursework/project, where I was responsible for designing and implementing the complete **Hatirjheel scene module**.

## Features

### Dynamic Animations

* Vehicle movement across the bridge
* Boat movement on water
* Flying bird animation

### Weather System

* Rainfall simulation
* Dynamic rain control

### Time Modes

* Day View
* Evening View
* Night View

### User Interaction

| Key                | Function                 |
| ------------------ | ------------------------ |
| D                  | Day Mode                 |
| E                  | Evening Mode             |
| N                  | Night Mode               |
| H                  | Increase Animation Speed |
| L                  | Decrease Animation Speed |
| P                  | Pause/Resume Animation   |
| Left Mouse Button  | Stop Rain                |
| Right Mouse Button | Start Rain               |

## How to Run

### Requirements

* CodeBlocks / Visual Studio
* OpenGL
* GLUT

### Compilation

```bash
g++ main.cpp -o Hatirjheel -lGL -lGLU -lglut
```

### Run

```bash
./Hatirjheel
```
